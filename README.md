# Hinário Unificado — instaladores

Este repositório guarda **só os instaladores e o aviso de atualização** do app Hinário Unificado
(uso interno da igreja). O código é privado.

- **Baixar o app (Android):** https://beustman.github.io/hinario-unificado
- **Versões e APKs:** aba [Releases](https://github.com/Beustman/hinario-unificado/releases)

Quem já tem o app instalado não precisa baixar nada por aqui: ao abrir, o app avisa que há versão nova e
atualiza com um toque. Os atrelamentos (mesclas), os recentes e as configurações de cada pessoa
continuam no aparelho depois da atualização.

Arquivos:

| Arquivo | Para que serve |
|---|---|
| `versao.json` | aviso de atualização lido pelo app (versão, novidades, endereço e SHA-256 do APK) |
| `index.html` | página de download |
| `NOTAS.md` | novidades da versão, em texto |
| `partituras_hn.json` | lista das partituras do Hinário Novo no Google Drive |
